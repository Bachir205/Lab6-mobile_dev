# Tic-Tac-Toe React Native App

A React Native version of the classic tic-tac-toe game, built by following the official React tutorial.

## Run locally

```bash
npm install
npx expo start
```

Open the app in Expo Go or an emulator to play.

## Features

- 3x3 interactive board
- Turn-based gameplay for X and O
- Winner detection and draw handling
- Move history with time-travel navigation
- Mobile-friendly layout
